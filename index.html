Can EEG signals tell us a seizure is happening?

A full walkthrough of a project that turns raw scalp EEG recordings into a tested, statistically validated seizure-detection pipeline — and an honest answer to whether fancier features actually help.

The story

The data comes from the Bonn EEG benchmark: single-channel recordings split into five groups — Z and O (healthy, eyes open/closed), F and N (interictal, i.e. epileptic but not currently seizing), and S (ictal / seizure). For the main task, Z+O+F+N (400 recordings) were treated as "non-seizure" against S (100 "seizure") recordings — a realistic 4:1 imbalance.

The question driving the project: global frequency-domain features (band power, spectral shape) already classify seizures extremely well. Do temporal dynamics — how those bands change moment to moment — add anything on top? Click through the workflow below to see how that question was answered, one step at a time.

The pipeline

Every model in this project was evaluated the same way: normalize using training-fold statistics only (never touching test data), then validate with stratified cross-validation.

Which classifier wins?

Six models were compared with 5-fold cross-validation on the 500-recording global-feature set. Random Forest and Bagged Trees came out on top.

Do temporal dynamics actually help?

This was the central experiment: a paired, repeated 10×5-fold cross-validation comparing Global features against Global+temporal variants, using identical folds so the comparison is apples-to-apples, then testing the differences with a Wilcoxon signed-rank test.

What it all means

Global features are already enough

Ten spectral/statistical features get to ~98% accuracy and 0.999 AUC on their own. That's the real headline.

Temporal features are informative, not additive

They carry real signal (high individual importance, large effect sizes) but overlap heavily with what global features already capture.

Framing matters: this is a benchmark classification study on a well-separated public dataset — not a validated clinical seizure detector. Bonn's classes come from different subjects/conditions, which makes separation easier than real intra-patient detection.
